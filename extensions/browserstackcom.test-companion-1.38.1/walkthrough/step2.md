# Customize Your Companion

**Tailor the AI's behavior and set up common inputs to ensure all generated output fits your project perfectly.**

---

# Using Rules: Align with Your Standards

Custom **rules** guide how the AI generates output.  
Use them to:
- Enforce your organization’s standards
- Maintain consistent tone and structure
- Provide vital context about your workspace

---

# Using Workflows: Automate Repeated Inputs

Use **Workflows** to save time by defining reusable setups. 

Avoid repeating basic inputs (e.g., URLs or credentials) by creating a lightweight custom workflow.
